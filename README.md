# AstrBot 话痨王插件 (Talkative King)

一个用于 AstrBot 的群组发言统计插件，能够统计群员每日发言次数并生成精美的排行榜图片，支持**定时自动广播**今日榜单到所有群聊。

## ✨ 功能特点

- **精美图片榜单**：生成包含头像、昵称、排名和发言次数的排行榜图片，支持自定义背景。
- **自动清理缓存**：自动清理超过 5 分钟的过期榜单图片，避免长期运行占用硬盘空间。
- **完美支持特殊符号**：内置 `pilmoji` 支持，完美渲染 Emoji 和颜文字（如 `( 。v_v 。)`），告别乱码。
- **智能触发**：
  - **模糊匹配**：忽略指令中的空格、标点符号（如 `今日 壁画王！` 也能触发）。
  - **抗干扰**：无论是否 @机器人，或者指令包含前缀，都能精准响应。
- **精准时间控制**：强制使用 **北京时间 (UTC+8)**，每日 **00:00** 准时重置数据并归档。
- **数据安全**：
  - **原子化保存**：防止断电或崩溃导致数据丢失。
  - **智能昵称保护**：自动识别并保留用户的有效昵称，防止被“QQ号”覆盖。
- **昨日回溯**：支持查看昨日榜单，精准还原昨日数据。
- **定时自动发送**：支持设定 **24 小时制**时间点，到点自动推送今日壁画王到目标群，与手动指令互不干扰。
- **一键广播所有群**：开启开关后无需逐个填群号，自动向所有已记录过消息的群聊广播今日榜单。

## 🚀 安装方法

1. 将 `astrbot_plugin_talkative_king` 文件夹放入 AstrBot 的 `data/plugins/` 目录下。
2. 确保安装了必要的依赖库：
   ```bash
   pip install -r requirements.txt
   ```
   *(主要依赖：Pillow, pilmoji, emoji)*
3. 重启 AstrBot 或在 WebUI 管理面板重载插件。

## 📖 使用指南

### 📅 今日排行榜
查看当天的发言统计排行。

- **触发关键词**（支持任意组合，如 `/今日发言` 或 `@Bot 今日壁画王`）：
  - `今日壁画王`
  - `今日发言`
  - `今日排行`
  - `今日发言排行榜`

查看昨天的发言统计排行。

- **触发关键词**：
  - `昨日壁画王`
  - `昨日发言`
  - `昨日排行`
  - `昨日发言排行榜`

## ⚙️ 高级配置

你可以在 AstrBot 的 WebUI **管理面板 -> 配置 -> 插件配置** 中找到本插件。
- **自定义背景图**：直接在面板中上传一张图片作为榜单背景。上传后插件会自动生效，并将内置的默认背景图删除以节省空间。如果不上传，则默认使用原有的粉色二次元风格背景。
- **字体支持**：默认使用 `msyh.ttc` (微软雅黑)，如遇生僻字可自动回退到系统字体。

### ⏰ 定时自动发送今日壁画王

在 WebUI 插件配置页可直接填写以下配置项，实现每天定点自动推送今日榜单：

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `auto_send_enabled` | 开关 | 关闭 | 启用后才会触发定时发送 |
| `auto_send_time` | 文本 | `08:00` | 发送时间，**24小时制**，格式 `HH:MM`，以北京时间(UTC+8)为准。例如 `08:00`、`21:30` |
| `auto_send_all_groups` | 开关 | 关闭 | **一键广播**：开启后向所有已记录过消息的群聊自动推送，无需填写下方群号 |
| `auto_send_groups` | 列表 | 空 | 目标群号列表（仅在「一键广播」关闭时生效），每行一个群号 |

**两种目标模式（互斥）：**
- **一键广播模式**（推荐）：开启 `auto_send_all_groups`，机器人会向所有它**加入过并接收过至少一条消息**的群聊广播今日榜单，无需手动维护群号列表。
- **指定群号模式**：关闭 `auto_send_all_groups`，在 `auto_send_groups` 中逐个填写目标群号。

**工作机制：**
- 后台每 60 秒检查一次是否到达设定时间，到达后对目标群逐一主动推送。
- 与手动指令完全互不干扰：到点前用户仍可随时用 `今日壁画王` 等命令查看。
- 每群每天仅发送一次，防止同一分钟内重复触发；次日 00:00 数据重置后自动恢复可发。
- 发送前会自动按北京时间重置当日数据，确保推送的是最新榜单。

**使用前提：**
- 机器人需已加入目标群，并**至少在该群内接收过一次消息**（用于记录会话标识）。首次部署后建议在目标群里 @机器人 发条消息即可。
- 推送采用 AstrBot 官方主动推送接口（`unified_msg_origin` + `context.send_message`）。
